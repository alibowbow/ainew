# API pricing review — 2026-09-24

The catalog displays a price status for every model. Verified prices use the model vendor's own API pricing page; a model release announcement alone does not establish an API price. The list is a snapshot, not a live quote. USD, CNY and platform credits are kept in their original currencies and units; prices are not converted or ranked across units.

- **Verified:** Standard, pay-as-you-go rates with billing unit, vendor source and checked date. Open weights with an identifiable first-party API, such as DeepSeek and GLM, have a separate API price; this never implies free hosting.
- **Provider-dependent:** Open weights without a unique first-party API tariff. Deployment or third-party hosting costs are separate.
- **No public rate / unverified:** Product or preview access, discontinued new-user API access, or an API listing without a source establishing this exact model's current price. No zero or estimated cost is implied.

Important conditions: Google's Gemini 3.8 promotional rates expire after 2026-12-31; GPT-5.6 Sol promotional rates are guaranteed at least through 2026-11-21. DeepSeek has peak/off-peak rates; the card shows the off-peak uncached input rate. Video, audio, and image prices use seconds, songs, output tokens or generation credits, as listed. Alibaba Cloud rates are for the specified Beijing region. Batch, context thresholds, caching, grounding, tool calls, location and subscription discounts can change the total bill; see the model's pricing detail and linked vendor sheet.
