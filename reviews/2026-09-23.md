## Later on September 23: Google speech

Checked 2026-09-23 UTC. [Google's September 23 announcement](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-text-to-speech/) launched **Gemini 3.8 Flash TTS** and **Gemini 3.8 Flash-Lite TTS**, with a phased rollout in Gemini API and Google AI Studio from the same date. The [Flash API specification](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-tts) and [Flash-Lite API specification](https://ai.google.dev/gemini-api/docs/models/gemini-3.8-flash-lite-tts) confirm the model IDs `gemini-3.8-flash-tts` and `gemini-3.8-flash-lite-tts`, text input/audio output, an 8,192-token input limit and 130/101 supported languages respectively. [Google DeepMind's Gemini 3.8 Audio model card](https://deepmind.google/models/model-cards/gemini-3-8-audio/) confirms both are API-distributed; weights and an open license are not offered. Announcement date, release/rollout date and first API date are recorded separately as 2026-09-23; neither is marked preview. Enterprise API availability is planned later, so this API date only refers to Gemini API.

Google's launch article reports **71.4** overall and **60.8** accent modeling for Flash TTS on the *Hume AI Voice Design Benchmark*. Both are recorded as index points in **two distinct metrics**, provider-reported, with unknown evaluation run date, detailed harness and tool budget. The official statement identifies a #2 place for Flash-Lite on a different *Hume Overall Quality Index* but publishes no numeric score; none was inferred. The Voice Arena language-specific placements are also qualitative only and are not registered as scores. The linked Google DeepMind model card dates itself to September 15, before the launch; model release dates come from the September 23 announcement rather than the card's original publication date. The API spec lists 16,384 output tokens while the model card lists 64K output tokens; output capacity was omitted pending clarification.
