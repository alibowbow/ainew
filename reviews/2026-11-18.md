# 모델·벤치마크 검토 2026-11-18 KST

## 신규 모델과 공개 상태

- GPT-6.2 Astra와 Sol은 11월 17일 ChatGPT Work, Codex 및 API에 출시됐다. 컨텍스트는 각각 1,050,000 토큰이다. 표준 API 입력·출력은 100만 토큰당 Astra $8·$40, Sol $2·$10이다. [공식 발표](https://openai.com/index/introducing-gpt-6-2-astra-sol/) · [Astra API](https://developers.openai.com/api/docs/models/gpt-6.2-astra) · [Sol API](https://developers.openai.com/api/docs/models/gpt-6.2-sol)
- Gemini 4 Carbon은 10월 28일 제한 프리뷰에서 11월 10일 일반 유료 API로 확대됐다. 11월 30일까지의 도입가와 12월 1일부터 적용되는 단가를 등록했다. Hydrogen의 기존 출시 기록에는 최신 평가를 연결했고, Gemini Robotics 2.5는 11월 10일 발표와 파트너 사용을 기록했다. [Carbon 출시](https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-4-carbon-now-available/) · [Gemini API 가격](https://ai.google.dev/gemini-api/docs/pricing) · [Hydrogen 모델 카드](https://deepmind.google/models/model-cards/gemini-4-hydrogen/) · [Robotics 발표](https://deepmind.google/blog/gemini-robotics-2-5-accelerates-real-world-physical-intelligence/)
- Qwen4-Max는 11월 16일 정식 API가 공개됐다. 11월 11일 프리뷰는 기존 항목에 보존했다. Tencent의 Hy4 Flash는 11월 16일 API 출시를 반영했다. Ling 3.2 Flash는 Ant Group 공식 변경 기록의 11월 5일을 적용했다. 3개 모델은 이번 검토에서 API 접근을 확인했다. [Alibaba Cloud 발표](https://www.alibabacloud.com/en/press-room/alibaba-unveils-qwen4-max) · [Tencent 발표](https://www.tencent.com/tencent-launches-hy4-flash-to-power-high-speed-cost-efficient-ai-deployment-for-everyday-workflows/) · [Ant Ling 변경 기록](https://developer.ant-ling.com/en/docs/getting-started/changelog)
- LG AI연구원의 K-EXAONE 2.5는 11월 9일 공개된 무료 API 모델로 추가했다. [LG AI연구원 발표](https://www.lgresearch.ai/news/view?seq=754)
- 공개 가중치 6종을 반영했다. Inkling 2 Small의 공개 상태를 Apache-2.0으로 갱신하고 Praxis-1, LongCat-Video-Avatar 1.6, Perplexity Decider 및 Decider Flash v1.3, Nemotron Labs Sigma Distill Spec 3B를 추가했다. LongCat-Video-Avatar는 MIT, Praxis-1과 Perplexity Decider 두 종은 Apache-2.0, Nemotron은 NVIDIA 전용 라이선스다. [Inkling 발표](https://thinkingmachines.ai/news/inkling-2-small/) · [Runway 발표](https://runway.com/news/company-news/praxis-1-is-now-available) · [Meituan 모델 카드](https://huggingface.co/meituan-longcat/LongCat-Video-Avatar-1.6) · [Perplexity 모델 카드](https://huggingface.co/perplexity-ai/pplx-decider-v1.3) · [Flash 모델 카드](https://huggingface.co/perplexity-ai/pplx-decider-flash-v1.3) · [NVIDIA 모델 카드](https://huggingface.co/nvidia/Nemotron-Labs-Sigma-distill-spec-3B)
