# AI Model Atlas

주요 AI 모델의 출시일과 벤치마크 신호를 한 화면에서 탐색하는 정적 리서치 인터페이스입니다.

## 포함 범위

- 2023년부터 2026년 8월까지의 주요 릴리즈 28개
- OpenAI, Anthropic, Google, Meta, DeepSeek, Qwen, xAI, Mistral 계열
- GPQA Diamond, SWE-bench, AIME 또는 수학·추론, MMMU 또는 OSWorld 중심의 비교표
- 연도·모델 계열·검색·정렬 필터
- 모델 상세 카드, 공식 발표문 링크, 비교 고정 기능

## 데이터 원칙

출시일은 공식 발표일을 우선했습니다. 점수는 각 제공자가 발표한 설정과 측정 방식에 따라 기록했으며, 동일한 조건의 단일 순위표로 해석하지 않습니다. 발표문에 대표 수치가 없거나 직접 비교가 어려운 값은 비워 두었습니다.

모델별 카드를 열면 대표 신호와 출처를 함께 볼 수 있습니다. 사이트 하단의 Source Register는 1차 발표자료 링크를 모아 둔 목록입니다.

## 실행

별도의 빌드 도구 없이 index.html을 브라우저에서 열면 됩니다. GitHub Pages를 사용하는 경우 Pages source를 main 브랜치의 root로 설정하면 됩니다.

## 디자인 메모

AI 연구 인덱스의 편집 화면을 콘셉트로 삼았습니다. 어두운 잉크색 사이드 레일, 따뜻한 종이색 캔버스, 라임 신호색을 사용해 일반적인 SaaS 대시보드와 구분되는 정보 밀도와 리듬을 만들었습니다. 좁은 화면에서는 사이드 레일이 접히고 벤치마크 표는 의도적인 가로 스크롤 영역으로 전환됩니다.
